一、汝、爾、子、若、君、卿（你）

意義（詞性）例句（出處）
你，代詞
「汝」既不田，而戲賊人稻（第11課，注釋⑤）
「汝」狗猛耶（第14課，課本標註）

汝＝爾＝子＝若＝君＝卿，都是「你」的意思（課本標註）。

二、副詞：聊、戲、大、果、乃

意義（詞性）例句（出處）
隨便、隨意地，副詞
「聊」取之耳（第11課，注釋④）
而「戲」賊人稻（第11課，課本標註）
非常、很，副詞
侃「大」怒曰（第11課，課本標註）
郡守果「大」怒（第13課，課本標註）
「盛」怒則差（第13課，補充）
果然，副詞
郡守「果」大怒（第13課，補充）
於是，副詞
「乃」多受其貨而不加治（第13課，補充）

副詞用來修飾動詞或形容詞：副→動詞（「聊」取、「大」怒）、副→形容詞（「未」熟稻，補充）。「乃」的其他用法見 6–10 課（於是、才）。

四、惟…是…／惟…之為…（賓語前置）

意義（詞性）例句（出處）
只，副詞
「惟」讀書是務（第12課，課本標註）
「惟」弈秋之為聽（第15課，課本標註）
「是」：賓語前置的助詞（不必翻譯）
惟讀書「是」務＝惟務讀書（第12課，課本標註）
惟馬首「是」瞻＝惟瞻馬首（第12課，課本標註）
「之為」：賓語前置的助詞（不必翻譯）
惟弈秋「之為」聽＝惟聽弈秋（第15課，課本標註）
何為＝為何，疑問代詞賓語前置
用此「何為」＝用此為何（做什麼）（第11課，注釋③）

正常語序：務讀書、聽弈秋、瞻馬首。把受詞提到動詞前面，並用「是」「之為」標示，語氣更強，有「只、專」的意思。

六、及、就、或、去

意義（詞性）例句（出處）
及：等到

就：前往，動詞
「就」閭里士人家借而讀之（第12課，注釋⑧）

「或」因而抄錄（第12課，注釋⑩）

意義（詞性）例句（出處）

各課重點

第11課　陶侃惜穀　《晉書》

詞語意思
陶侃晉代名臣、名將，為人忠順勤勞，擔任荊州刺史時，曾每日搬運磚塊以鍛鍊體力，傳為美談
嘗曾經
何為即為何，做什麼用
行道走路（課本標註）
聊隨便
汝你
不田不耕種
賊損害
執抓起來
給富裕

課本隨堂練習答案：1. C　2. D　3. C　4. A

「執而鞭之」省略主詞，主詞是陶侃（課本標註 S：陶侃）；這個「之」指持稻的人。

成語「家給人足」：家家富裕，人人滿足。

名句精讀：「大禹之聖，且惜寸陰；陶侃之賢，且惜分陰；又況賢聖不若彼者乎？」（激問；勸人要愛惜光陰。）

第12課　畫荻教子　《宋史》

詞語意思
歐陽公指歐陽脩
孤幼年喪父或無父母
資錢財
太夫人本文指歐陽脩的母親
荻蘆葦一類的植物
書寫
及等到
就前往
閭里鄉里
或有時
誦背誦
寢食睡覺和吃飯；泛指日常生活
務致力從事

課本隨堂練習答案：1. B　2. B　3. C　4. C

歐陽脩是北宋著名的文學家、史學家。「畫荻」比喻母親教導子女有方（母教良好）。

「惟讀書是務」＝只致力讀書（賓語前置，課本標註：務讀書）。

失怙＝父亡（無父何怙）；失恃＝母亡（無母何恃）。

第13課　華佗治病　晉．陳壽《三國志》

詞語意思
郡守郡的最高長官（郡是古代行政單位）
佗東漢名醫華佗，擅長外科手術，是中國第一個用麻醉劑為病人開刀治療的醫生
差病癒，通「瘥」
貨財物
無何沒多久
去離開（課本標註）
書信
逐追趕
瞋恚氣憤發怒
愈通「癒」，病情好轉

課本隨堂練習答案：1. C　2. C　3. D　4. B

「其人」的「其」指郡守；「郡守子知之」的「之」指追殺華佗這件事（課本標註）。

文學常識「杏林」：借代醫學界；「杏壇」：借代教育界；「岐黃」：借指醫術（見補充）。

第14課　宋人酤酒　《韓非子》

詞語意思
酤賣（「而往酤」的「酤」則是「買」，課本標註）
升量酒器
概量
幟酒旗
售賣出
故原因
畏害怕、恐懼
孺子小孩子
挈提、拿
迓迎接
齕用牙齒咬

課本隨堂練習答案：1. D　2. A　3. B　4. C

「怪其故，問其所知」的主詞是宋人（課本標註 S：宋人）；「而狗迓而齕之」的「之」指孺子。

成語「狗猛酒酸」：比喻小人得勢當道，使賢才無法被任用（隨堂練習第 2 題）。

第15課　二子學弈　《孟子》

詞語意思
弈動詞，下棋
秋人名，因為他善於下棋，所以被稱為弈秋
通國全國
善善於、擅長
誨動詞，教導
鴻鵠天鵝
援引、拉
弓繳繫在箭尾的繩子為繳，弓繳則是指繫有絲繩的箭
俱一起
弗若不如
與嗎
非然不是這樣

課本隨堂練習答案：1. C　2. B　3. A　4. B

「雖與之俱學，弗若之矣」的兩個「之」，都指專心致志向弈秋學習的人（課本標註）。

智慧諺語：「敗棋有勝著」——雖然下輸了棋，過程中仍會有高明之處；比喻要有眼光，才能善用人才。

智慧諺語：「觀棋不語真君子」——看別人下棋時，不要干擾下棋者的思路；或比喻不要多管閒事。

虛字練習（課文中的虛字）

  1. 「汝既不田」的「汝」，與下列哪一個字的意思「不同」？
    汝＝爾＝子＝若＝君＝卿，都是「你」；吾是「我」。
  2. 「聊取之耳」的「聊」，意思是？
    聊：隨便（注釋④）。聊取之耳＝隨便拿一把罷了。
  3. 「而戲賊人稻」的「賊」，在句中的詞性和意思是？
    賊：損害（注釋⑦）。「賊」本來是名詞，這裡轉用成動詞（轉品）。
  4. 下列哪一個字在句中「沒有」轉品（詞性沒有改變）？
    田（耕種）、賊（損害）、鞭（用鞭子打）都由名詞轉成動詞；「稻」仍是名詞。
  5. 「就閭里士人家借而讀之」的「之」，指的是什麼？
    借書來讀，「之」指書。
  6. 「雖與之俱學，弗若之矣」的兩個「之」，都是指？
    與「他」（專心的人）一起學，還是不如「他」。
  7. 「惟讀書是務」的「是」，作用是？
    「惟讀書是務」＝惟務讀書：把受詞「讀書」放到動詞「務」前面，用「是」標示。
  8. 下列哪一個句子的語序，與「惟弈秋之為聽」相同（賓語前置）？
    惟馬首是瞻＝惟瞻馬首，與「惟弈秋之為聽」（惟聽弈秋）相同。
  9. 「及稍長」的「及」，意思是？
    及：等到（注釋⑦）。與第 7、9 課的「比」「迨」意思相近。
  10. 「或因而抄錄」與「或令孺子懷錢」的「或」，意思依序是？
    或因而抄錄：有時（注釋⑩）；或令孺子……：有的人（課本標註）。
  11. 「為酒甚美」的「為」，意思是？
    為酒＝釀酒、製作酒，「為」是動詞（課本標註）。
  12. 「佗以為其人盛怒則差」的「以為」，意思是？
    以為＝認為。
  13. 「宋人有酤酒者」與「而往酤」的「酤」，意思依序是？
    注釋①：酤＝賣；「而往酤」的「酤」，指去買酒（課本標註）。
  14. 「盛怒則差」的「差」與「吐黑血數升而愈」的「愈」，意思是？
    差通「瘥」、愈通「癒」，都是病好了。
  15. 「故後世以岐黃為醫家之祖」的「故」，意思是？
    這裡的「故」是連詞，表示因果，相當於「所以」。
  16. 「其智弗若與」的「弗若」與「與」，意思依序是？
    弗若＝不如（注釋⑩）；與＝嗎（注釋⑪），是疑問語氣詞。

成語與文學常識

  1. 「杏林」與「杏壇」，依序借代什麼？
    杏林借代醫學界（董奉的故事）；杏壇借代教育界（課本標註）。
  2. 「術精岐黃」的「岐黃」，指的是什麼？
    岐黃是岐伯和黃帝的合稱，《黃帝內經》托名於兩人問答論醫，後世以岐黃為醫家之祖。
  3. 「又況賢聖不若彼者乎？」使用了哪一種設問修辭？
    激問：答案在問題的反面。意思是：連大禹、陶侃都珍惜光陰，何況不如他們的人，更應該珍惜。
  4. 「失怙」與「失恃」，依序是指？
    「無父何怙」→ 失怙＝父亡；「無母何恃」→ 失恃＝母亡（課本標註）。
  5. 「觀棋不語真君子」的意思最接近下列何者？
    智慧諺語：看別人下棋時，不要干擾下棋者；或比喻不要多管閒事。

字形辨析：誨、晦、悔、侮

  1. 「教誨」與「悔不當初」的「誨」「悔」，讀音依序是？
    誨（教導）讀ㄏㄨㄟˋ；悔（事後追恨）讀ㄏㄨㄟˇ。
  2. 「欺侮」的「侮」，意思是？
    侮（ㄨˇ）＝欺凌。
  3. 「風雨如晦」與「韜光養晦」，依序比喻什麼？
    風雨如晦：比喻處於險惡環境中也不改變其操守；韜光養晦：比喻隱藏才能，不使外露。
  4. （甲）教＿　（乙）＿不當初　（丙）欺＿　（丁）隱＿。空格依序應填入？
    教誨（教導）、悔不當初（事後追恨）、欺侮（欺凌）、隱晦（不顯明）。

第11課　陶侃惜穀　《晉書》

  1. 陶侃問路人「用此何為」，是想知道什麼？
    「何為」即「為何」，做什麼用（注釋③）。
  2. 路人回答「行道所見，聊取之耳」，意思是？
    行道＝走路，聊＝隨便，耳＝罷了。
  3. 陶侃罵「汝既不田，而戲賊人稻」，責備的重點是什麼？
    既不田：不耕種；戲賊人稻：隨意損害別人的稻子。
  4. 從陶侃處置持稻人的做法，最能看出他是怎樣的人？
    導讀：陶侃體恤農人的辛勞，愛護莊稼而執法嚴格，因此百姓勤於耕種，家給人足。

第12課　畫荻教子　《宋史》

  1. 歐陽脩四歲失去父親，家中沒錢買紙筆，母親怎麼教他識字？
    「太夫人以荻畫地，教以書字」。
  2. 歐陽脩長大後，家裡沒有書可讀，他怎麼解決？
    「就閭里士人家借而讀之，或因而抄錄」。
  3. 「以至晝夜忘寢食，惟讀書是務」，形容歐陽脩什麼？
    忘寢食＝忘了睡覺和吃飯；惟讀書是務＝只致力於讀書。
  4. 「自幼所作詩賦文字，下筆如成人」，這句話的意思是？
    下筆如成人：寫出來的作品，已經像成人一樣好。

第13課　華佗治病　晉．陳壽《三國志》

  1. 華佗接受郡守許多財物後，接著做了什麼事？
    「乃多受其貨而不加治，無何棄去，留書罵之」。
  2. 「郡守果大怒，令人追捉殺佗」，這句話說明了什麼？
    「果」＝果然，郡守真的大怒，正是華佗所預期的結果。
  3. 郡守的兒子知道追殺華佗的事後，為什麼「囑使勿逐」？
    導讀：郡守的兒子知道華佗的用意，囑咐使吏不要追趕。
  4. 這個故事最能表現華佗的哪一項特點？
    華佗看出郡守的病可藉大怒來治，故意激怒他，使他吐出胸中瘀積的黑血而痊癒。

第14課　宋人酤酒　《韓非子》

  1. 下列哪一項「不是」課文提到宋人賣酒的優點？
    課文提到升概甚平、遇客甚謹、為酒甚美、懸幟甚高，沒有提到店面整潔。
  2. 宋人為什麼去請教楊倩？
    「怪其故，問其所知」。
  3. 楊倩說「人畏焉」，人們畏懼的是什麼？
    前面問「汝狗猛耶」，可知人們害怕的是那隻猛狗。
  4. 楊倩舉出「令孺子懷錢挈壺甕而往酤，而狗迓而齕之」的例子，目的是什麼？
    連派小孩去買酒都被狗咬，客人自然不敢再來，酒因此賣不掉而變酸。

第15課　二子學弈　《孟子》

  1. 「通國之善弈者也」的意思是？
    通國＝全國；善＝擅長；弈者＝下棋的人。
  2. 「其一人專心致志，惟弈秋之為聽」的意思是？
    惟弈秋之為聽＝惟聽弈秋（賓語前置）。
  3. 另一個人「一心以為有鴻鵠將至」，接著他心裡想做什麼？
    「思援弓繳而射之」：想拿起繫著絲繩的箭去射牠。
  4. 孟子回答「非然也」，是要說明什麼？
    「為是其智弗若與？」問的是：難道是他的智力不如嗎？「非然也」答：不是這樣，關鍵在於是否專心。
